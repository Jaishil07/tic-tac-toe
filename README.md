# tic-tac-toe
A simple tic-tac-toe game, made with html, css, javascript and my tears.


This project is made as a part of the Odin Project, you can visit the odin link, [here](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe)

The objectives were to have minimum global code in Javascript.

This was my first time creating a game, it was fun and it needed a bit of brainstorming but at the end we go there, I will come back to neat up the UI in the future and add animations when I learn them.

To visit the live website, [click here](https://jaishil07.github.io/tic-tac-toe/). Have Fun!
